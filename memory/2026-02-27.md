## 技术笔记

### 日志格式
普通服务器和 K8s 的日志格式基本一致：
```
[traceId,spanId,parentId] [IP:Port] [用户(userId)] 时间 [线程] 级别 类名 (文件:行) -- 内容
```

### Loki 查询方式
通过 Grafana 代理 API：
```
GET /api/datasources/proxy/{datasource_id}/loki/api/v1/query_range
?query={app="xxx"}&start=xxx&end=xxx&limit=5000
```

### 慢接口阈值
第别确认：1s（医疗信息化场景，稳定流畅比极致性能更重要）
