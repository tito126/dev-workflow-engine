## OpenCode exec 调用测试

### 测试结果
| 方式 | 命令 | 模型支持 | 结果 |
|------|------|----------|------|
| exec | `npx -y opencode-ai run -m <model>` | ✅ 支持 | ✅ 成功获取响应 |

**测试时间**：2026-04-04 01:52

**测试1**：使用智谱 glm-5
- 命令：`npx -y opencode-ai run -m "zhipuai-coding-plan/glm-5" "Say hello and tell me what model you are running on."`
- 结果：✅ 成功
- 响应内容：OpenCode 成功识别并使用了智谱 glm-5 模型

- 响应原文：`> build · glm-5` 和 `Hello! I'm running on the glm-5 model (zhipuai-coding-plan/glm-5).`

**结论**：OpenCode 的 `run` 子命令 + `-m` 参数可以成功指定模型并获取响应。

### 耗时分析

| 阶段 | 耗时 |
|-----|------|
| npx 启动 | ~3-5秒 |
| 构建项目 | ~1-2秒 |
| 模型响应 | ~1-2秒 |
| **总耗时** | **~5-9秒** |

**结论**：简单的 "Hello" 查询大约需要 5-9 秒完成，主要耗时在 npx 启动和构建阶段。

### 为什么这么慢？

1. **npx 冷启动**：首次运行需要下载/缓存包
2. **构建/初始化**：OpenCode 需要准备运行环境
3. **模型调用**：实际推理需要时间

## Codex 模型配置

- 当前配置: `model_provider = "packycode"`
- packyapi.com 代理目前不支持智谱模型
- 如需使用智谱模型，需要在配置中添加 provider
