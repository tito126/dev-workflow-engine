### 经验教训

1. **端口配置**：
   - OpenClaw 的 Web 界面在 Gateway 端口（18789），不是独立的 3000 端口
   - 需要查看实际的日志和 netstat 输出来确认端口

2. **bind 配置**：
   - 不能随意设置，只能用预定义的值
   - 使用 `openclaw doctor --fix` 可以修复配置错误

3. **CORS 配置**：
   - origin 是页面本身的地址，不是访问者的 IP
   - 需要允许 Gateway 自己的 Tailscale IP

4. **安全上下文**：
   - 浏览器的某些功能需要 HTTPS 或 localhost
   - SSH 隧道是最简单的解决方案

5. **保守策略**：
   - 在关键时期（工作日前夜）不要冒险切换
