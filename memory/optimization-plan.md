#### 3. 异常影响级别分析（新增）
**背景**：
- 用户发现：`[rpc-exec-123]`、`[enc-2196]` 等异步/并发线程的异常可能不影响主流程
- 应该降低这些异常的级别

**方案**：
- 分析每个trace的线程类型
- 判断是否影响主流程：
  - `[Jetty-Worker_xxx]` → 影响主流程（HTTP请求）→ 高影响
  - `[winning-winex-*_Jetty-Worker_xxx]` → 影响主流程（跨服务HTTP）→ 高影响
  - `[rpc-exec-xxx]` → 可能不影响主流程（异步RPC）→ 中影响
  - `[enc-xxx]` → 不影响主流程（异步任务）→ 低影响
  - 其他线程 → 中影响

**实施**：
1. 在 `categorize_trace` 中，分析线程类型
2. 返回 `impact_level`（high/medium/low）
3. 在报告中显示"影响级别"
4. 在统计时，高影响级别的异常排在前面

**示例**：
```python
def analyze_impact_level(trace_logs):
    """分析trace的影响级别"""
    for log in trace_logs:
        thread = log.get('thread', '')
        
        # HTTP请求线程 → 高影响
        if 'Jetty-Worker' in thread:
            return 'high'
    
    # 检查是否有异步线程
    for log in trace_logs:
        thread = log.get('thread', '')
        
        # 异步任务线程 → 低影响
        if thread.startswith('[enc-'):
            return 'low'
        
        # RPC调用线程 → 中影响
        if thread.startswith('[rpc-exec-'):
            return 'medium'
    
    # 默认中影响
    return 'medium'
```
