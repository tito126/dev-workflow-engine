# 日志猎人 PPT 版本差异提炼

对比版本：
- 第一版：`work-system/deliverables/日志猎人-AI技术大赛答辩PPT-2026-03-20.pptx`
- 最后一版：`work-system/deliverables/log-hunter-ai-presentation-2026-03-21-v11-notes.pptx`

这份文档不追求逐字比对，而是提炼对后续复用真正有价值的结构差异、页面差异和可迁移结论。

## 一、总体差异

### 1. 项目定位变化
- 第一版：更像“已有成果展示”
- 最后一版：更像“围绕明确主线的答辩论证”

### 2. 叙事重点变化
- 第一版重点回答：我们做了什么
- 最后一版重点回答：为什么做、为什么值得、后面还能走到哪

### 3. 技术表达位置变化
- 第一版：技术路径本身存在感较强
- 最后一版：技术表达退居支撑位，服务于价值表达和治理闭环

### 4. 成果页作用变化
- 第一版：成果展示偏“结项说明”
- 最后一版：成果展示偏“价值证据”

## 二、逐页核心差异

### P1 封面
- 第一版：标准封面页，承担了“项目呈现开始”的作用
- 最后一版：进一步压缩为极简开场，不提前承载项目介绍
- 可迁移结论：封面只负责开场，不要抢项目介绍页的职责

### P2 团队介绍
- 第一版：成员分工展示较标准，偏模板化
- 最后一版：团队职责更聚焦真实分工，并补入“协同支持”且表达克制、事实化
- 可迁移结论：团队页不要过度技术化，也不要夸大外部支持，重在可信

### P3 议程/项目导入
- 第一版：更接近模板式目录页，说明四大章节
- 最后一版：除了目录，还承担正式导入项目的职责，把“为什么做”真正讲出来
- 可迁移结论：目录页可以兼做项目导入，但前提是封面页必须足够克制

### P4 项目背景与目标
- 第一版：背景、目标、价值都写到了，但表达更偏完整陈述
- 最后一版：明确收敛为“事后响应偏多”这一核心问题，并把目标改写为闭环式能力建设
- 可迁移结论：背景页要有单一痛点，避免同时铺太多问题

### P5 技术思路与实现
- 第一版：更突出采集、分析、输出、应用四段式能力链
- 最后一版：仍有技术步骤，但重点变成“日志如何从原始文本变成持续创造价值的输入”
- 可迁移结论：技术页不能只讲链路，要回答这条链路为什么有意义

### P6 能力深化
- 第一版：偏“核心能力列表 + 关键优化点”
- 最后一版：改成“能力边界”表达，把自然语言巡检、GC 日志、代表 trace 等放到更合理的位置
- 可迁移结论：进阶能力不要堆成清单，要说明它扩展了什么边界

### P7 应用价值/验证闭环
- 第一版：更多在讲阶段成果、应用价值、应用场景、推广前景
- 最后一版：集中讲“发现 -> 分析 -> AI 辅助修复 -> 再验证”的闭环雏形
- 可迁移结论：价值页最好讲机制，而不只是讲场景

### P8 总结展望
- 第一版：标准总结展望页
- 最后一版：更强调阶段变化，即从被动排查走向持续优化和治理闭环
- 可迁移结论：总结页最好总结“认知跃迁”而不是重复成果列表

### P9 成果展示 01
- 第一版：成果与价值表达分散在前后几页中
- 最后一版：单页聚焦“整体问题画像”，让成果页承担快速建立判断的作用
- 可迁移结论：成果第一页要帮助评委快速形成全局认知

### P10 成果展示 02
- 第一版：成果更多停留在“我们有这些输出”
- 最后一版：更突出异常明细、代表 trace、慢接口等如何支持定位和优化行动
- 可迁移结论：成果第二页要从“展示结果”切换到“证明能行动”

### P11 未来规划
- 第一版：偏标准化未来规划
- 最后一版：未来规划和现有能力、日志质量、AI 辅助修复、验证闭环之间连接更紧
- 可迁移结论：未来规划不要悬空，要从当前能力自然生长出来

### P12 Q&A
- 第一版：标准结束页
- 最后一版：因前面已经把主线收稳，Q&A 页更像自然收口
- 可迁移结论：Q&A 页本身不重要，重要的是前面是否已经把问题讲顺

## 三、真正值得复用的结构升级

### 1. 从“展示型 PPT”升级为“答辩型 PPT”
核心不是页面更漂亮，而是每页都在服务同一条主线。

### 2. 从“功能链”升级为“价值链”
第一版更像能力说明；最后一版更像在论证：这套能力如何帮助发现问题、推动优化、形成闭环。

### 3. 从“成果罗列”升级为“证据组织”
成果不再只是证明做过，而是证明为什么值得相信。

### 4. 从“内容完成”升级为“上场完整”
最后一版背后已经包含备注、讲稿、口语版、Q&A，这代表交付思路发生了变化。

## 四、后续可直接复用的检查问题

以后做比赛型/汇报型项目时，可以先过这几题：
- 这套 PPT 的主线能否用一句话说清
- 封面、目录、背景页是否职责清楚
- 技术页是在讲能力，还是在讲能力为什么有价值
- 成果页是在展示输出，还是在证明可判断、可行动、可复用
- 未来规划是不是从当前成果自然长出来的
- 除了页面，是否同步准备了讲稿、口语版和 Q&A

## 五、结论

这次版本演进最重要的不是文案变好了，而是完成了三次关键转换：
- 从“展示成果”到“论证价值”
- 从“讲技术路径”到“讲治理主线”
- 从“做完 PPT”到“准备上场”

这三次转换，才是后续最值得迁移到其他项目中的核心资产。
