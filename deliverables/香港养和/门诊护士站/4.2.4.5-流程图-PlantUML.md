## 4.2.4.5.2 患者列表加载流程

```plantuml
@startuml
start
:用户进入患者列表页面或切换筛选条件;
:系统读取诊区、日期、Tab、状态、医生、看诊方式、关键字等条件;
:查询 outp_nurse_checkin 当前态记录;
:查询 outp_checkin_tag 当前有效标签;
:按需补充最近一次有效示踪摘要;
:加载统一页面显示配置;
:按列表列配置渲染患者列表;
:返回刷新时间及分页结果;
stop
@enduml
```

## 4.2.4.5.3 HIS Check In 接诊写入流程

```plantuml
@startuml
start
:接收 HIS Check In 请求;
:读取 requestId;
if (是否已成功处理?) then (是)
  :直接返回幂等成功结果;
else (否)
  :校验患者、诊区、就诊、医生等必要参数;
  if (是否包含预约/医嘱来源信息?) then (是)
    :写入/更新 outp_nurse_checkin_order;
  else (否)
  endif
  :生成/更新 outp_nurse_checkin 主记录;
  :初始化当前状态为待分流或约定初始状态;
  :写入 outp_sync_status;
  :记录统一处理日志;
  :返回处理结果;
endif
stop
@enduml
```

## 4.2.4.5.4 外部系统推送患者流转流程

```plantuml
@startuml
start
:接收外部流转事件请求;
:读取 requestId、sourceEventId;
if (是否已成功处理?) then (是)
  :直接返回幂等成功结果;
else (否)
  :校验 checkinId、节点信息、来源系统信息;
  :写入 outp_nurse_transfer 新事件;
  :根据节点类型判断当前状态、当前去向、当前医生、最近事件信息;
  :回写 outp_nurse_checkin 当前态字段;
  if (是否涉及标签变化?) then (是)
    :更新 outp_checkin_tag;
    :记录 outp_checkin_tag_log;
  else (否)
  endif
  :写入 outp_sync_status;
  :记录统一处理日志;
  :返回处理结果;
endif
stop
@enduml
```

## 4.2.4.5.5 护士手工补录患者流向流程

```plantuml
@startuml
start
:护士点击“示踪”;
:填写患者流向、备注、操作时间等信息;
:系统校验当前接诊记录是否有效;
if (校验是否通过?) then (通过)
  :写入 outp_nurse_transfer 补录事件;
  if (是否影响当前去向?) then (是)
    :更新 outp_nurse_checkin 当前去向及最近事件;
  else (否)
  endif
  :按规则生成/失效去向标签;
  :记录统一处理日志;
  :返回新增成功并刷新列表;
else (不通过)
  :返回失败原因;
endif
stop
@enduml
```

## 4.2.4.5.6 结束就诊 / 提前结束就诊流程

```plantuml
@startuml
start
:护士点击“结束就诊”或“提前结束就诊”;
:系统校验患者当前状态与业务前置条件;
if (校验是否通过?) then (通过)
  :接收结束原因、提前结束原因及后续引用信息;
  :写入 check out 类事件到 outp_nurse_transfer;
  :更新 outp_nurse_checkin 的 check out 状态相关字段;
  if (是否存在后续入院单/转介单引用?) then (是)
    :保存后续引用快照摘要;
  else (否)
  endif
  :失效或更新相关去向/状态标签;
  :写入 outp_sync_status;
  :记录统一处理日志;
  :返回处理结果并刷新列表;
else (不通过)
  :返回失败原因;
endif
stop
@enduml
```

## 4.2.4.5.7 逆流程处理

```plantuml
@startuml
start
:接收 reverse / 回本中心 / 撤销修正请求;
if (事件类型?) then (外部系统撤销节点)
  :定位 outp_nurse_transfer 原事件;
  if (原事件是否存在?) then (是)
    :新增 reverse 事件;
    :更新原事件有效性/撤销关联;
    :重新计算并回写 outp_nurse_checkin 当前态;
    :修正相关标签;
  else (否)
    :返回原事件不存在;
  endif
elseif (回本中心)
  :新增“回本中心” transfer 事件;
  :更新当前去向为本中心;
  :按规则恢复待接诊、待回诊或其他状态;
elseif (护士手工补录修正)
  :记录修正后的新事件或撤销事件;
  :回写主表当前态;
  :保留原始操作痕迹;
elseif (check out 回退)
  :新增逆向事件;
  :修正 check out 相关字段;
  :恢复 outp_nurse_checkin 对应状态;
  :重新生成或失效相关标签;
endif
:记录统一处理日志;
stop
@enduml
```

## 4.2.4.5.8 幂等、重试与对账处理流程

```plantuml
@startuml
start
:接收外部请求或扫描失败记录;
if (幂等校验已成功?) then (是)
  :直接返回已处理结果;
else (否)
  :执行正常业务逻辑;
  if (处理是否成功?) then (成功)
    :更新 outp_sync_status = SUCCESS;
  else (失败)
    :更新 outp_sync_status = FAILED;
    :更新 retry_count、next_retry_time、error_message;
    if (重试次数是否超限?) then (未超限)
      :进入重试队列;
    else (已超限)
      :标记异常，等待人工处理;
    endif
  endif
endif
:定时执行对账任务;
:比对外部记录与我方同步状态;
if (存在差异?) then (是)
  :执行补录 / 重试 / 修正;
  :必要时按最新有效事件重新归并当前态;
else (否)
  :结束;
endif
stop
@enduml
```
