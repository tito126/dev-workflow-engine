# Temporary Work Pool

Use this file as the main inbox for temporary operational items.

## Status Legend

- `pending`: captured and waiting for handling
- `moved`: transferred into a project or another formal destination
- `done`: completed
- `archived`: no longer needed
- `dropped`: intentionally abandoned

## Item Template

```md
### [T-YYYYMMDD-01] Short title
- Created: YYYY-MM-DD HH:MM
- Type: task | idea | risk | pending-confirmation | reminder
- Source: leader | self | meeting | colleague | system
- Related Project: none | <project name>
- Priority: high | medium | low
- Status: pending
- Content: one clear sentence
- Next Handling: clarify / execute / move to project / set reminder / archive
```
