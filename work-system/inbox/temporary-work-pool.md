# Temporary Work Pool

## Status Legend

- `pending`: captured and waiting for handling
- `moved`: transferred into a project or another formal destination
- `done`: completed
- `archived`: no longer needed
- `dropped`: intentionally abandoned

```md
- Priority: high | medium | low
- Status: pending
- Content: one clear sentence
- Next Handling: clarify / execute / move to project / set reminder / archive
```
