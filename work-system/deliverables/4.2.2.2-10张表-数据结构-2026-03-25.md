# 4.2.2.2 核心表结构数据结构（按 4.2.2.2.4.2 风格整理）

> 说明：以下数据结构参考 `4.2.2.2.4.2 日程操作日志表（outp_schedule_log）` 的呈现格式整理，统一采用“字段名 / 类型 / 说明”方式描述，便于直接贴入详设文档。

## 4.2.2.2.2.1 表1：诊区（中心）配置表（outp_clinic_zone_config）

用于维护诊区中心级别的日程表基础配置和运行参数。

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键，自增 |
| clinic_zone_id | VARCHAR(50) | 诊区ID |
| clinic_zone_code | VARCHAR(50) | 诊区编码 |
| clinic_zone_name | VARCHAR(100) | 诊区名称 |
| center_id | VARCHAR(50) | 所属中心ID |
| center_name | VARCHAR(100) | 所属中心名称 |
| default_start_time | VARCHAR(10) | 默认开始时间，如 `08:00` |
| default_end_time | VARCHAR(10) | 默认结束时间，如 `18:00` |
| time_step_length | INT | 时间步长，单位分钟 |
| row_height | INT | 时段行高，单位像素 |
| column_width | INT | 资源列宽，单位像素 |
| support_multi_day_view | TINYINT(1) | 是否支持未来多日视图：0-否，1-是 |
| callback_url | VARCHAR(255) | 三方回调地址 |
| callback_enabled | TINYINT(1) | 是否启用回调：0-否，1-是 |
| status | VARCHAR(20) | 状态：ENABLED（启用）/ DISABLED（停用） |
| remark | VARCHAR(500) | 备注 |
| create_by | VARCHAR(50) | 创建人 |
| create_time | DATETIME | 创建时间 |
| update_by | VARCHAR(50) | 修改人 |
| update_time | DATETIME | 修改时间 |

| update_time | DATETIME | 更新时间 |

## 附：建议统一说明

1. 所有表的主键字段可按项目统一规范决定是否使用自增 `id` + 业务主键双字段模式。
2. 所有涉及三方调用、组件回调、人工新增的业务数据，均建议保留 `request_id` 用于幂等和追溯。
3. `reservation_type` 应作为日程看板按预约类型着色展示的核心字段之一。
4. 如后续文档中还需补“索引建议 / 主外键关系 / 枚举值字典”，建议在本结构基础上继续展开，不要再改动这 10 张表的主口径。
