## 需求澄清

- 类型：易用性优化 + 流程一致性优化
- 背景：现有“长期医嘱首日”相关规则和流向应用是分散配置的，用户容易只看到参数入口，但不知道该参数实际影响哪一层、是否直接改变发药/执行行为、以及还需要去哪里完成联动配置。
- 目标：在护士站配置入口提供足够清晰、可执行的参数说明，帮助用户正确理解“首日”标识规则及其与物资流向配置的联动关系，降低误配置和理解成本。
- 非目标：
  - 不在本轮整合多个产品线的配置入口
  - 不在本轮改造“首日”业务计算规则本身
  - 不在本轮直接调整医嘱流向引擎或药房分配逻辑
  - 不默认包含新的自动校验、联动跳转或配置向导
- 范围：
  - 住院护士站配置页面中 `长期医嘱首日设置` 的参数说明展示
  - 与说明内容直接相关的文案、交互承载方式、帮助提示
  - 需要核对说明内容是否准确映射到 `基础配置 -> 公共配置 -> 医嘱流向配置 -> 住院 -> 药品 -> 物资流向`
- 成功标准：
  1. 用户能在参数配置入口直接理解“首日”标识是什么
  2. 用户能理解“首日”标识只对执行计划赋标有效，不等于直接完成流向控制
  3. 用户能知道若要落地业务效果，还需配置医嘱物资流向
  4. 示例说明足以帮助用户区分“首日=是/否”对应的流向差异
  5. 说明内容与现有实际业务规则一致，不制造新歧义
- 允许改动层级 / 禁止改动层级：
  - 允许：页面说明文案、帮助提示、说明承载区块、必要的前端展示优化
  - 谨慎允许：与说明展示直接相关的配置项元数据或渲染方式
  - 禁止：首日规则算法、流向规则引擎、接口协议、数据库对象、跨产品线配置整合方案
- 建议验收方式 / 衡量口径：
  - 代码完成：说明内容已落到对应配置入口，展示正常
  - 需求完成：说明覆盖“意义、作用范围、联动配置位置、案例”四类关键信息
  - 效果已验证：需要业务/产品或现场使用方确认，说明内容能支撑正确配置，不再出现“只配参数、不配流向”类理解偏差
- 外部依赖 / 前置条件：
  - 需确认现网/当前版本的“首日”业务规则与流向联动规则没有额外口径差异
  - 需确认文案是否已由产品/需求侧最终定稿
  - 若存在医院特化规则，需明确本次说明是标准产品口径还是项目定制口径
- 风险 / 模糊点：
  - TFS 中给出了说明草案，但未明确最终 UI 承载形式（静态说明、tooltip、帮助弹层、富文本区域）
  - 未明确是否需要在页面上提供跳转或关联提示到流向配置页
  - 未明确是否已有历史误解案例，导致说明粒度还需再细化
