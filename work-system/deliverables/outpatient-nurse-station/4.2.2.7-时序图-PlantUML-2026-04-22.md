# 4.2.2.7 时序图 - PlantUML

> 用途：作为 `4.2.2.7 时序图` 章节的直接素材。
> 本版按 Banner 模块当前约定的“两接口”口径绘制：

> 2. Banner 业务值查询接口

---

## 4.2.2.7.1 设计说明

本节用于描述门诊护士站患者 Banner 模块在关键场景下的跨对象交互顺序，重点体现：
- 前端页面、配置项接口、业务值接口之间的调用顺序；
- `INP_BANNER_DISPLAY_ADAPT` 与 `BANNER_DISPLAY_WARD_SETTINGS` 的读取时点；
- 患者基础信息与动态业务值的查询时点；
- Banner 最终渲染与悬浮展示的形成顺序。

本版时序图优先覆盖以下三个核心场景：
1. 患者 Banner 整体加载时序；
2. Banner 配置项查询时序；
3. Banner 业务值查询与前端展示时序。

## 4.2.2.7.2 患者 Banner 整体加载时序图

```plantuml
@startuml
hide footbox

autonumber

actor "操作员" as User
participant "门诊护士站前端页面" as Page
participant "Banner 配置项接口\n/api/outpatient-nurse/banner/config-items" as ConfigApi
participant "Banner 配置服务" as ConfigService
database "INP_BANNER_DISPLAY_ADAPT\nBanner 基础显示项表" as Adapt
database "BANNER_DISPLAY_WARD_SETTINGS\nBanner 病区配置表" as WardSetting
participant "Banner 业务值接口\n/api/outpatient-nurse/banner/business-values" as ValueApi
participant "Banner 业务值服务" as ValueService
participant "患者基础信息服务" as PatientBaseService
participant "患者扩展属性服务" as PatientPropertyService

User -> Page: 打开单患者菜单
Page -> ConfigApi: 查询 Banner 配置项(wardId, encounterTypeCode, emergencyTypeCode, appSystemCode)
ConfigApi -> ConfigService: 转发配置项查询请求
ConfigService -> Adapt: 查询基础显示项定义
Adapt --> ConfigService: 返回基础项列表
ConfigService -> WardSetting: 查询病区展示配置
WardSetting --> ConfigService: 返回病区配置列表
ConfigService -> ConfigService: 关联配置并按规则补齐、排序
ConfigService --> ConfigApi: 返回 configItems
ConfigApi --> Page: 返回 Banner 配置项列表

Page -> ValueApi: 查询 Banner 业务值(patientId, bannerDisplayItemIds)
ValueApi -> ValueService: 转发业务值查询请求
ValueService -> PatientBaseService: 查询固定信息
PatientBaseService --> ValueService: 返回头像、序号、性别、年龄
ValueService -> PatientPropertyService: 按 propertyName 查询动态业务值
PatientPropertyService --> ValueService: 返回属性名与属性值映射
ValueService -> ValueService: 组装固定信息与动态展示项
ValueService --> ValueApi: 返回 Banner 最终数据
ValueApi --> Page: 返回 fixedItems + dynamicItems

Page -> Page: 渲染 Banner
alt 一行展示不下
  Page -> Page: 悬浮时展示完整信息
else 正常展示
  Page -> Page: 直接展示全部 Banner 内容
end
@enduml
```

## 4.2.2.7.3 Banner 配置项查询时序图

```plantuml
@startuml
hide footbox

autonumber

participant "门诊护士站前端页面" as Page
participant "Banner 配置项接口\n/api/outpatient-nurse/banner/config-items" as ConfigApi
participant "Banner 配置服务" as ConfigService
database "INP_BANNER_DISPLAY_ADAPT\nBanner 基础显示项表" as Adapt
database "BANNER_DISPLAY_WARD_SETTINGS\nBanner 病区配置表" as WardSetting
collections "统一日志留痕机制" as OpLog

Page -> ConfigApi: 查询 Banner 配置项
ConfigApi -> ConfigService: 校验并处理请求
ConfigService -> Adapt: 按 appSystemCode / hospitalSoid 查询基础项
Adapt --> ConfigService: 返回基础显示项定义
ConfigService -> WardSetting: 按 wardId / 场景参数查询病区配置
WardSetting --> ConfigService: 返回病区配置
ConfigService -> ConfigService: 按 BANNER_DISPLAY_ITEM_ID 关联配置
alt 命中病区特定配置
  ConfigService -> ConfigService: 取病区特定配置结果
else 未命中特定配置
  ConfigService -> ConfigService: 按默认项规则补齐
end
ConfigService -> ConfigService: 过滤逻辑删除项并按 SEQ_NO 排序
ConfigService -> OpLog: 记录配置项查询日志
ConfigService --> ConfigApi: 返回 configItems, hoverEnabled
ConfigApi --> Page: 返回配置项查询结果
@enduml
```

## 4.2.2.7.4 Banner 业务值查询与前端展示时序图

```plantuml
@startuml
hide footbox

autonumber

participant "门诊护士站前端页面" as Page
participant "Banner 业务值接口\n/api/outpatient-nurse/banner/business-values" as ValueApi
participant "Banner 业务值服务" as ValueService
participant "患者基础信息服务" as PatientBaseService
participant "患者扩展属性服务" as PatientPropertyService
collections "统一日志留痕机制" as OpLog

Page -> ValueApi: 查询 Banner 业务值(patientId, bannerDisplayItemIds)
ValueApi -> ValueService: 校验并处理请求
ValueService -> PatientBaseService: 查询固定信息
PatientBaseService --> ValueService: 返回头像、序号、性别、年龄
ValueService -> ValueService: 汇总 propertyName 列表
ValueService -> PatientPropertyService: 查询动态业务值
PatientPropertyService --> ValueService: 返回属性值映射
loop 遍历 bannerDisplayItemIds
  alt 配置项为固定文案类
    ValueService -> ValueService: 取配置中的固定展示值
  else 配置项为动态业务类
    alt 查询到动态值
      ValueService -> ValueService: 写入对应 displayValue
    else 未查询到动态值
      ValueService -> ValueService: 返回空值
    end
  end
end
ValueService -> ValueService: 组装 fixedItems 与 dynamicItems
ValueService -> OpLog: 记录业务值查询日志
ValueService --> ValueApi: 返回 Banner 最终数据
ValueApi --> Page: 返回 fixedItems + dynamicItems + hasOverflow
Page -> Page: 按排序渲染动态展示项
alt hasOverflow = true
  Page -> Page: 鼠标悬浮时展示完整内容
else hasOverflow = false
  Page -> Page: 正常展示 Banner 内容
end
@enduml
```
