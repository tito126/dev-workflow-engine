# 4.2.7.4 模块接口

## 4.2.7.4.1 设计说明

本节接口分为两类：

- 后台接口
- 调用其他模块接口

其中：

- 护士站后台接口负责承接本模块自身的列表查询、签收请求转发、护士站自有字段维护及页面展示组装。
- 医嘱主数据、主状态、签收结果、审方、收费、转录、医技预约、入院单等能力继续由医生站、HIS、药房、医技系统提供，护士站通过模块调用或接口调用方式接入。
- 需要幂等控制的写接口统一复用 4.2.3 的 `outp_sync_status`、统一日志留痕与统一配置能力。
- 页面展示状态、可签收性、可编辑性及执行计划展示控制，以医生站及相关外部系统返回结果为准，护士站后台接口不重复定义主状态语义。

## 4.2.7.4.2 后台接口

### 4.2.7.4.2.1 医嘱列表查询接口

- **接口地址：** `GET /api/outpatient-nurse/order/list`
- **功能说明：** 按患者当前就诊上下文查询医嘱列表，读取医生站医嘱主数据并按需关联 `outp_nurse_order_ext`，返回页面展示所需的状态、摘要信息及页面操作控制信息。
- **调用方：** 门诊护士站前端页面
- **触发时机：**
  - 页面初始化
  - 切换患者
  - 筛选条件变更
  - 签收、编辑、转录等操作后刷新列表

**请求参数：**

- `checkinId`
- `encounterId`
- `patientId`
- `orderCategory`
- `onlyUnsign`
- `statusList`
- `displayConfigVersion`

**返回结果：**

- 医嘱列表分页或全量数据
- 医生站主状态
- 医生站返回的签收结果
- 页面展示状态
- 新、废、改标识
- 审方、收费等摘要信息
- 是否可签收、是否可编辑、是否可查看详情、是否展示执行计划

**异常处理：**

- 参数非法时返回失败信息
- 查询异常时写错误日志
- 该接口不通过 `outp_sync_status` 做幂等处理，但需保留访问日志与错误日志

### 4.2.7.4.2.2 医嘱签收接口

- **接口地址：** `POST /api/outpatient-nurse/order/sign`
- **功能说明：** 接收护士发起的医嘱签收请求，完成参数校验和幂等控制后，调用医生站签收接口执行处理，并将结果返回前端。
- **调用方：** 门诊护士站前端页面
- **触发时机：** 护士在医嘱列表中勾选医嘱后点击【签收】按钮

**请求参数：**

- `requestId`
- `checkinId`
- `encounterId`
- `operatorId`
- `operatorName`
- `operateTime`
- 待签收医嘱集合

**返回结果：**

- 是否处理成功
- 每条医嘱的签收结果
- 每条医嘱的最新展示状态
- 是否需要刷新列表
- 失败原因明细

**异常处理：**

- 使用 `requestId` 进行幂等校验
- 若医生站返回不可签收原因，则直接透传给前端
- 失败时写入 `outp_sync_status`
- 关键处理过程写入统一日志留痕机制
- 重试与对账策略复用 4.2.3.5.8

### 4.2.7.4.2.3 医嘱属性编辑回写接口

- **接口地址：** `POST /api/outpatient-nurse/order/edit`
- **功能说明：** 接收护士对医嘱属性的编辑请求，调用医生站接口完成主数据更新后，将护士站自有辅助字段回写到 `outp_nurse_order_ext`。
- **调用方：** 门诊护士站前端页面
- **触发时机：** 护士点击医嘱列表中的【编辑】按钮并提交修改时

**请求参数：**

- `requestId`
- `checkinId`
- `encounterId`
- `orderId`
- `orderCategory`
- `doctorEditableFields`
- `nurseOwnFields`
- `operatorId`
- `operatorName`
- `operateTime`

**返回结果：**

- 是否处理成功
- `orderId`
- 医生站字段更新结果
- 护士站自有字段更新结果
- 最新展示属性摘要
- 最新可操作状态

**异常处理：**

- 使用 `requestId + orderId` 进行幂等校验
- 若医生站返回字段不可编辑，则返回失败说明
- 若病理类医嘱发起编辑，直接拒绝处理
- 失败时写入 `outp_sync_status`
- 关键处理过程写入统一日志留痕机制

### 4.2.7.4.2.4 护士站医嘱扩展数据查询接口

- **接口地址：** `GET /api/outpatient-nurse/order/ext`
- **功能说明：** 按医嘱主键查询护士站自有辅助字段，用于页面详情区、编辑弹框等场景。
- **调用方：** 门诊护士站前端页面
- **触发时机：**
  - 医嘱行展开查看详情
  - 打开编辑弹框

**请求参数：**

- `checkinId`
- `orderId`
- `orderCategory`

**返回结果：**

- `retainDrugMode`
- `nurseRemark`
- 更新时间及维护人信息（如有）

**异常处理：**

- 查询异常时写错误日志
- 无扩展记录时返回空对象，不视为失败

## 4.2.7.4.3 调用其他模块接口

### 4.2.7.4.3.1 门诊医生站医嘱详情查看组件

- **调用场景：** 护士选中医嘱后点击页面顶部【查看】按钮，需在下方详情区查看医嘱详情，并按医嘱类型决定是否展示执行计划
- **调用入口：** 医嘱处理区域顶部【查看】按钮

**核心入参：**

- `orderId`
- `encounterId`
- `patientId`
- `orderCategory`
- `source = OUTPATIENT_NURSE_ORDER`

**核心出参：**

- 医嘱详细内容
- 医生站主状态
- 签收结果
- 审方、收费、执行等主结果摘要
- `hasExecutionPlan`
- 执行计划内容（如有）

**调用后处理：**

- 查看按钮统一放置于页面顶部
- 若 `hasExecutionPlan = true`，则展示详情区中的执行计划部分
- 若 `hasExecutionPlan = false`，则仅展示医嘱详情，不展示执行计划区域
- 护士站只做展示，不修改主数据

### 4.2.7.4.3.2 门诊医生站医嘱属性编辑组件或接口

- **调用场景：** 护士点击【编辑】按钮后，需由医生站判断哪些字段允许修改并完成主数据更新
- **调用入口：** 医嘱列表行操作区中的【编辑】按钮

**核心入参：**

- `orderId`
- `orderCategory`
- `checkinId`
- `patientId`
- `doctorEditableFields`
- `operatorId`
- `operatorName`

**核心出参：**

- 是否更新成功
- 医生站认可的最终字段值
- 当前可编辑字段范围
- 是否仍允许签收

**调用后处理：**

- 医生站更新成功后，护士站再更新 `outp_nurse_order_ext`
- 若医生站拒绝修改，则护士站不回写本地辅助字段
- 页面提示以医生站返回结果为准

### 4.2.7.4.3.3 门诊医生站医嘱转录组件

- **调用场景：** 护士点击【转录】按钮，调用医生站提供的组件开立医嘱
- **调用入口：** 医嘱处理区域右上方【转录】按钮

**核心入参：**

- `checkinId`
- `encounterId`
- `patientId`
- `clinicId`
- `doctorId`
- `source = OUTPATIENT_NURSE_ORDER`
- `operatorId`
- `operatorName`

**核心出参：**

- 是否转录成功
- 新开立医嘱主键集合
- 是否需医生确认
- 是否进入审批流程
- 是否需要刷新列表

**调用后处理：**

- 护士站不直接写医生站医嘱主表
- 若转录结果为待确认或待审批，则对应医嘱不可签收
- 返回成功后刷新医嘱列表展示

### 4.2.7.4.3.4 HIS 补记账组件

- **调用场景：** 护士点击【补记账】按钮，调用 HIS 记账组件执行补记账
- **调用入口：** 医嘱处理区域右上方【补记账】按钮

**核心入参：**

- `encounterId`
- `patientId`
- `orderId` 或选中的医嘱集合
- `patientVisitScope`
- `operatorId`
- `operatorName`

**核心出参：**

- 是否处理成功
- 补记账单据主键
- 费用处理结果
- 是否刷新医嘱收费标识

**调用后处理：**

- 住院患者补记账、门诊患者补记账调用不同组件
- 主收费结果以 HIS 为准
- 护士站仅负责页面刷新，不重复落库收费主结果

### 4.2.7.4.3.5 护理文书报价单组件

- **调用场景：** 护士打开护理文书中的费用预估单，并导入当前医嘱数据生成报价单
- **调用入口：** 医嘱处理区域右上方【报价单】或护理文书中的费用预估单入口

**核心入参：**

- `checkinId`
- `encounterId`
- `patientId`
- `selectedOrderIds`
- `quoteType`
- `operatorId`
- `operatorName`

**核心出参：**

- `quoteDocId`
- 已导入医嘱集合
- 是否允许打印
- 是否允许继续手工补充项目

**调用后处理：**

- 护士站不单独维护报价单主表
- 报价文书由护理文书模块负责归档与打印
- 如返回结果要求刷新页面，则重新加载当前视图

### 4.2.7.4.3.6 医技预约组件或系统接口

- **调用场景：** 护士点击【医技预约】按钮，调医技预约界面进行预约、修改、取消、查看操作
- **调用入口：** 医嘱处理区域右上方【医技预约】按钮

**核心入参：**

- `checkinId`
- `encounterId`
- `patientId`
- `orderId`
- `orderCategory`
- `source = OUTPATIENT_NURSE_ORDER`

**核心出参：**

- `appointmentId`
- `appointmentStatus`
- `appointmentTime`
- 是否需要刷新医嘱列表

**调用后处理：**

- 医技预约系统负责主业务处理
- 护士站只做上下文透传和结果回显
- 需要刷新页面时，直接重新查询医嘱列表或详情数据

### 4.2.7.4.3.7 门诊医生站入院单组件

- **调用场景：** 护士点击患者列表中的入院单提醒图标，或右侧功能按钮【入院单】时，打开门诊医生站入院单组件
- **调用入口：** 患者列表入院单提醒图标、医嘱处理区域或右侧功能按钮【入院单】

**核心入参：**

- `checkinId`
- `encounterId`
- `patientId`
- `admissionNoteId`
- `source = OUTPATIENT_NURSE_ORDER`

**核心出参：**

- 是否成功打开
- `admissionNoteId`
- 入院单状态
- 是否需要刷新提醒标识

**调用后处理：**

- 入院单主数据由医生站模块负责
- 护士站仅负责上下文透传与提醒标识刷新
- 如需在列表中展示“存在入院单”，以医生站返回结果为准

### 4.2.7.4.3.8 药房审方、发药及相关结果查询接口

- **调用场景：** 医嘱列表或详情区需要展示审方、收费、发药等药品相关结果时，需读取药房或相关系统返回的主结果
- **调用入口：**
  - 医嘱列表加载
  - 医嘱详情查看
  - 签收完成后刷新

**核心入参：**

- `orderId`
- `encounterId`
- `patientId`
- `orderCategory = DRUG`

**核心出参：**

- 审方结果
- 发药结果
- 费用状态摘要
- 页面展示所需的药品状态信息

**调用后处理：**

- 药房或相关系统结果为主，护士站不重复定义主状态
- 页面展示直接使用查询结果或刷新后的主数据
- 发生口径冲突时，以药房或医生站主结果优先
