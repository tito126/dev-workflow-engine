4.2.2.4 输入、输出

4.2.2.4.1 设计说明

本节用于说明门诊护士站患者 Banner 模块在典型业务场景下的输入与输出对象，重点描述系统在 Banner 加载、配置匹配和界面展示过程中接收什么业务数据、输出什么展示结果。

本节仅保留场景化输入输出说明和示例数据，不重复展开接口协议、调用责任、异常处理、配置维护流程等内容；相关正式接口定义统一放在 4.2.2.5 模块接口 中说明。

本模块当前主要覆盖以下两类输入输出场景：
患者 Banner 加载展示；
Banner 超长信息悬浮查看。

4.2.2.4.2 患者 Banner 加载展示输入输出

4.2.2.4.2.1 场景说明

当操作员在患者菜单患者列表中点击某一患者，打开单患者菜单时，系统需要加载并展示患者 Banner。Banner 固定展示头像、序号（HIS 患者登记序号）、性别、年龄；其他信息则按【统一配置-banner 组件-门诊护士站 banner】配置进行动态展示。

4.2.2.4.2.2 输入内容

输入内容主要包括：
患者基础信息；
患者登记序号；
当前病区 / 诊区信息；
就诊类型、急诊类型；
Banner 基础显示项定义；
病区 Banner 展示配置；
患者扩展属性值。

4.2.2.4.2.3 输出结果

系统完成 Banner 配置匹配和患者属性取值后，输出结果包括：
固定信息展示内容；
按顺序组装后的动态展示项列表；
各展示项的显示值、背景色、字体色等样式信息；

固定信息属于产品明确要求的固定展示项，不受病区配置关闭影响；
逻辑删除配置项或不匹配当前病区 / 就诊场景的配置项，不参与本次 Banner 渲染。

4.2.2.4.3 Banner 超长信息悬浮查看输入输出

4.2.2.4.3.1 场景说明

当患者 Banner 中动态展示项较多，或某些展示项内容较长导致界面一行显示不下时，系统支持操作员将鼠标悬浮到对应 Banner 区域查看完整信息。

4.2.2.4.3.2 输入内容

输入内容主要包括：
当前已渲染的 Banner 展示项；
当前界面可见区域内未完整展示的项；
操作员悬浮的目标展示区域；
完整展示值和样式信息。

输入示例如下：

JSON
{
  "patientId": "PAT_10001",
  "hoverTarget": "bannerOverflowArea",
  "overflowItems": [
    {
      "bannerDisplayItemId": "BDI_002",
      "displayItemName": "患者偏好",
      "displayValue": "希望优先安排女护士沟通"
    },
    {
      "bannerDisplayItemId": "BDI_003",
      "displayItemName": "备注",
      "displayValue": "近三月多次复诊，沟通时需同步关注既往检查结果"
    }
  ]
}

4.2.2.4.3.3 输出结果

系统输出结果包括：
当前溢出展示项的完整内容；
展示项名称和值；
悬浮层展示标志；
对应样式信息。

输出示例如下：

JSON
{
  "code": 200,
  "message": "悬浮信息加载成功",
  "data": {
    "patientId": "PAT_10001",
    "showTooltip": true,
    "tooltipItems": [
      {
        "displayItemName": "患者偏好",
        "displayValue": "希望优先安排女护士沟通"
      },
      {
        "displayItemName": "备注",
        "displayValue": "近三月多次复诊，沟通时需同步关注既往检查结果"
      }
    ]
  }
}

悬浮查看仅改变展示方式，不改变 Banner 原有配置与患者数据；
悬浮层展示内容应与 Banner 当前已匹配出的展示项保持一致，不允许出现配置外字段；
如当前所有 Banner 信息均已完整展示，则不触发悬浮查看输出。
