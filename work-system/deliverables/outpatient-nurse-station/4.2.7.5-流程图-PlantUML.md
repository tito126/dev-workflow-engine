## 4.2.7.5.2 医嘱列表加载流程

```plantuml
@startuml
start
:用户进入医嘱处理页面或切换筛选条件;
:系统读取 checkinId、encounterId、patientId、医嘱类别、状态筛选等条件;
:查询医生站医嘱主数据;
:查询 outp_nurse_order_ext 中的签收状态和护士扩展属性;
:加载护士端医嘱显示配置和可编辑字段配置;
:组装展示状态、标签和操作权限;
:按排序规则和列配置渲染医嘱列表;
:返回刷新时间及列表结果;
stop
@enduml
```

## 4.2.7.5.3 医嘱签收流程

```plantuml
@startuml
start
:接收医嘱签收请求;
:读取 requestId、signBatchNo;
if (是否已成功处理?) then (是)
  :直接返回幂等成功结果;
else (否)
  :校验 checkinId、医嘱集合、操作护士信息;
  :逐条校验是否允许签收;
  if (是否存在待确认/未审批生效医嘱?) then (是)
    :返回不可签收原因;
  else (否)
    if (是否存在护士侧属性变更?) then (是)
      :先调用医生站接口更新主数据;
    else (否)
    endif
    :写入/更新 outp_nurse_order_ext;
    if (医生站主状态=已签署?) then (是)
      :回写 nurse_sign_status = SIGNED_OFF;
    else (否)
      :回写 nurse_sign_status = VOID_SIGNED_OFF;
    endif
    :记录签收护士、签收时间、批次号;
    :写入 outp_sync_status;
    :记录统一处理日志;
    :返回签收结果及最终展示状态;
  endif
endif
stop
@enduml
```

## 4.2.7.5.4 医嘱属性编辑流程

```plantuml
@startuml
start
:接收医嘱属性编辑请求;
:读取 requestId、orderId;
if (是否已成功处理?) then (是)
  :直接返回幂等成功结果;
else (否)
  :校验 checkinId、orderId、医嘱类别、操作护士信息;
  if (是否为病理医嘱?) then (是)
    :拒绝处理并返回失败原因;
  else (否)
    :读取护士端显示配置和医生站字段控制信息;
    if (提交字段是否均可编辑?) then (是)
      :调用医生站接口更新主数据;
      if (医生站是否更新成功?) then (是)
        :同步更新 outp_nurse_order_ext;
        :回写最新展示属性和操作状态;
        :写入 outp_sync_status;
        :记录统一处理日志;
        :返回处理成功结果;
      else (否)
        :返回医生站更新失败原因;
      endif
    else (否)
      :返回字段不可编辑原因;
    endif
  endif
endif
stop
@enduml
```

## 4.2.7.5.5 外部组件调用协同流程

```plantuml
@startuml
start
:护士点击转录/补记账/报价单/医技预约/入院单入口;
:系统组装患者、就诊、医嘱、诊区、医生、护士等上下文;
:调用对应外部组件;
if (外部组件处理是否成功?) then (成功)
  if (是否需要刷新医嘱列表?) then (是)
    :重新执行医嘱列表加载流程;
  else (否)
  endif
  if (是否需要回写少量展示投影字段?) then (是)
    :进入投影回写流程;
  else (否)
  endif
  :返回页面刷新结果;
else (失败)
  :记录失败日志;
  :提示外部组件处理失败原因;
endif
stop
@enduml
```

## 4.2.7.5.6 外部主结果投影回写流程

```plantuml
@startuml
start
:接收外部主结果投影更新请求;
:读取 requestId;
if (是否已成功处理?) then (是)
  :直接返回幂等成功结果;
else (否)
  :校验来源系统、orderId 和投影字段内容;
  if (字段是否属于允许投影范围?) then (是)
    :写入/更新 outp_nurse_order_ext 投影字段;
    :保留来源系统、更新时间和追溯信息;
    :写入 outp_sync_status;
    :记录统一处理日志;
    :返回更新结果;
  else (否)
    :返回字段不允许投影原因;
  endif
endif
stop
@enduml
```

## 4.2.7.5.7 幂等、重试与对账处理流程

```plantuml
@startuml
start
:接收写接口请求或扫描失败记录;
if (幂等校验已成功?) then (是)
  :直接返回已处理结果;
else (否)
  :执行正常业务逻辑;
  if (处理是否成功?) then (成功)
    :更新 outp_sync_status = SUCCESS;
  else (失败)
    :更新 outp_sync_status = FAILED;
    :更新 retry_count、next_retry_time、error_message;
    if (重试次数是否超限?) then (未超限)
      :进入重试队列;
    else (已超限)
      :标记异常，等待人工处理;
    endif
  endif
endif
:定时执行对账任务;
:比对外部记录与我方同步状态;
if (存在差异?) then (是)
  :执行补录 / 重试 / 修正;
  :按医生站主状态 + 护士签收状态重新归并展示结果;
else (否)
  :结束;
endif
stop
@enduml
```
