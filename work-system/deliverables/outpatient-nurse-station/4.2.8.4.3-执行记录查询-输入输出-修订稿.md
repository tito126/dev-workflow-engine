# 4.2.8.4.3 输入、输出

## 4.2.8.4.3.1 设计说明

执行记录查询属于查询展示类功能，输入输出设计围绕以下两个核心场景展开：

- 查询患者医嘱及对应执行记录
- 查看指定医嘱的执行计划

其中：

- 医嘱基础信息由医生站提供
- 药品医嘱执行计划及执行记录由输液系统提供
- 治疗医嘱执行计划及执行记录由治疗系统提供
- 护士站负责汇总查询结果并返回页面展示数据

## 4.2.8.4.3.2 医嘱执行记录查询输入输出

### 4.2.8.4.3.2.1 场景说明

点击【医嘱执行-医嘱执行查询】后，系统按患者和筛选条件查询医嘱列表，并展示每条医嘱对应的执行记录摘要。对存在执行计划的医嘱显示“查看”按钮。

### 4.2.8.4.3.2.2 输入内容

输入内容主要包括：

- 接诊主键
- 就诊主键
- 患者主键
- 执行计划时间范围
- 医嘱类型
- 项目名称检索关键字
- 执行状态
- 是否全部未执行

输入示例如下：

```json
{
  "checkinId": "NC-20260421-0001",
  "encounterId": "OP202604210001",
  "patientId": "P00012345",
  "planBeginTime": "2026-04-21 00:00:00",
  "planEndTime": "2026-04-21 23:59:59",
  "orderCategoryList": ["DRUG", "TREATMENT"],
  "keyword": "阿莫西林",
  "execStatus": "ALL",
  "onlyAllUnexecuted": false
}
```

### 4.2.8.4.3.2.3 输出结果

输出结果主要包括：

- 医嘱基础信息
- 执行状态
- 执行计划时间
- 实际执行人
- 实际执行时间
- 实际执行科室
- 是否显示查看按钮

输出示例如下：

```json
{
  "success": true,
  "items": [
    {
      "orderId": "ORD-10001",
      "orderSortNo": 1,
      "orderTermType": "TEMP",
      "orderCategory": "DRUG",
      "orderStartTime": "2026-04-21 09:00:00",
      "orderItemName": "阿莫西林胶囊",
      "administrationRoute": "口服",
      "dosageDesc": "1粒",
      "frequencyDesc": "BID",
      "quantityDesc": "1盒",
      "orderExecDeptName": "门诊输液室",
      "execStatus": "UNEXECUTED",
      "planExecTime": "2026-04-21 10:00:00",
      "actualExecutorName": "",
      "actualExecTime": "",
      "actualExecDeptName": "",
      "showViewButton": true
    }
  ],
  "message": "查询成功"
}
```

## 4.2.8.4.3.3 执行计划查看输入输出

### 4.2.8.4.3.3.1 场景说明

用户点击列表中的“查看”按钮后，系统按医嘱类型调用对应执行系统接口，查询该医嘱的执行计划明细并返回页面展示。

### 4.2.8.4.3.3.2 输入内容

输入内容主要包括：

- 接诊主键
- 就诊主键
- 患者主键
- 医嘱主键
- 医嘱类型

输入示例如下：

```json
{
  "checkinId": "NC-20260421-0001",
  "encounterId": "OP202604210001",
  "patientId": "P00012345",
  "orderId": "ORD-10001",
  "orderCategory": "DRUG"
}
```

### 4.2.8.4.3.3.3 输出结果

输出结果主要包括：

- 执行计划列表
- 每条计划的计划时间
- 执行状态
- 实际执行人
- 实际执行时间
- 注射部位、批次号等补充信息（如有）

输出示例如下：

```json
{
  "success": true,
  "orderId": "ORD-10001",
  "planSourceSystem": "INFUSION",
  "planList": [
    {
      "planExecTime": "2026-04-21 10:00:00",
      "execStatus": "EXECUTED",
      "actualExecutorName": "李护士",
      "actualExecTime": "2026-04-21 10:08:00",
      "actualExecDeptName": "门诊输液室",
      "injectionSite": "左上臂",
      "batchNo": "VAC-20260421-01"
    }
  ],
  "message": "查询成功"
}
```
