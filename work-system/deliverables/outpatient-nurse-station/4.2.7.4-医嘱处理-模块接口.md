# 4.2.7.4 模块接口

## 4.2.7.4.1 设计说明

本节接口分为两类：

- 后台接口；
- 调用其他模块接口。

其中：

1. 护士站后台接口负责承接本模块自身的列表查询、签收、属性编辑结果回写和展示投影处理；
2. 医嘱主数据、主状态、审方、收费、转录、医技预约、入院单等能力继续由医生站、HIS、药房、医技系统提供，护士站通过模块调用或接口调用方式接入；
3. 需要幂等控制的写接口统一复用 `4.2.3` 的 `outp_sync_status`、统一日志留痕与统一配置能力；
4. 页面展示态由“医生站主状态 + 护士签收状态”组合生成，护士站后台接口不重复定义医生站主状态语义。

## 4.2.7.4.2 后台接口

### 4.2.7.4.2.1 医嘱列表查询接口

接口地址：`GET /api/outpatient-nurse/order/list`

功能说明：按患者当前就诊上下文查询医嘱列表，读取医生站医嘱主数据并关联 `outp_nurse_order_ext`，返回页面展示所需的状态、标签、护士补充属性和页面操作控制信息。

调用方：门诊护士站前端页面。

触发时机：

- 页面初始化；
- 切换患者；
- 筛选条件变更；
- 签收、编辑、转录后刷新列表。

请求参数：

- checkinId；
- encounterId；
- patientId；
- orderCategory；
- onlyUnsign；
- statusList；
- displayConfigVersion。

返回结果：

- 医嘱列表分页或全量数据；
- 医生站主状态；
- 护士签收状态；
- 页面展示状态；
- 新 / 废 / 改标识；
- 标签集合；
- 是否可签收 / 是否可编辑 / 是否可查看详情。

异常处理：

- 参数非法时返回失败信息；
- 查询异常时写错误日志；
- 该接口不通过 `outp_sync_status` 做幂等处理，但需保留访问日志与错误日志。

### 4.2.7.4.2.2 医嘱签收接口

接口地址：`POST /api/outpatient-nurse/order/sign`

功能说明：对勾选医嘱执行签收处理。若签收对象包含护士侧属性变更，则先调用医生站接口完成属性更新，再写入或更新 `outp_nurse_order_ext` 中的签收结果与补充字段。

调用方：门诊护士站前端页面。

触发时机：护士在医嘱列表中勾选医嘱后点击【签收】按钮。

请求参数：

- requestId；
- checkinId；
- encounterId；
- signBatchNo；
- operatorId、operatorName；
- operateTime；
- 待签收医嘱集合；
- 每条医嘱的护士补充属性。

返回结果：

- 是否处理成功；
- signBatchNo；
- 每条医嘱的签收结果；
- 每条医嘱的最终展示状态；
- 签收成功 / 失败原因明细。

异常处理：

- 使用 `requestId` + `signBatchNo` 进行幂等校验；
- 若存在待确认医嘱或未审批生效转录医嘱，则返回不可签收原因；
- 失败时写入 `outp_sync_status`；
- 关键处理过程写入统一日志留痕机制；
- 重试与对账策略复用 `4.2.3.5.8`。

### 4.2.7.4.2.3 医嘱属性编辑回写接口

接口地址：`POST /api/outpatient-nurse/order/edit`

功能说明：接收护士对医嘱属性的编辑请求，调用医生站接口完成主数据更新后，将护士站侧补充属性回写到 `outp_nurse_order_ext`。

调用方：门诊护士站前端页面。

触发时机：护士点击医嘱列表中的【编辑】按钮并提交修改时。

请求参数：

- requestId；
- checkinId；
- encounterId；
- orderId；
- orderCategory；
- editableFields；
- operatorId、operatorName；
- operateTime。

返回结果：

- 是否处理成功；
- orderId；
- 已更新字段集合；
- 最新展示属性摘要；
- 最新可操作状态。

异常处理：

- 使用 `requestId` + `orderId` 进行幂等校验；
- 若医生站返回字段不可编辑，则返回失败说明；
- 若病理类医嘱发起编辑，直接拒绝处理；
- 失败时写入 `outp_sync_status`；
- 关键处理过程写入统一日志留痕机制。

### 4.2.7.4.2.4 护士站医嘱扩展数据查询接口

接口地址：`GET /api/outpatient-nurse/order/ext`

功能说明：按医嘱主键查询护士站扩展字段，用于页面详情区、编辑弹框、签收前预览等场景。

调用方：门诊护士站前端页面。

触发时机：

- 医嘱行展开查看详情；
- 打开编辑弹框；
- 打开签收确认弹框。

请求参数：

- checkinId；
- orderId；
- orderCategory。

返回结果：

- 签收状态；
- 药品类扩展字段；
- 非药品类投影字段；
- editableFieldsSnapshot；
- 护士备注。

异常处理：

- 查询异常时写错误日志；
- 无扩展记录时返回空对象，不视为失败。

### 4.2.7.4.2.5 医技 / 收费 / 报告结果投影回写接口

接口地址：`POST /api/outpatient-nurse/order/projection/update`

功能说明：承接外部系统主结果在护士站侧的少量展示投影回写，例如预约状态、报告状态、医生通知标记、暂不收费标识、药房返回的发药辅助信息等。

调用方：医技系统、HIS、药房系统，或由本系统内部异步任务触发。

触发时机：

- 医技预约成功、修改、取消后；
- 补记账或收费主结果回传后；
- 报告生成或医生已读状态变化后；
- 药房发药或审方结果需在护士站展示时。

请求参数：

- requestId；
- sourceSystem；
- orderId；
- appointmentId、appointmentStatus（如有）；
- reportStatus（如有）；
- doctorNotifyFlag（如有）；
- projectionFields；
- operateTime。

返回结果：

- 是否处理成功；
- orderId；
- 已更新投影字段集合；
- 是否需要刷新医嘱列表。

异常处理：

- 使用 `requestId` 进行幂等校验；
- 失败时写入 `outp_sync_status`；
- 关键处理过程写入统一日志留痕机制；
- 该接口仅回写展示投影字段，不得覆盖医生站主状态语义。

## 4.2.7.4.3 调用其他模块接口

### 4.2.7.4.3.1 门诊医生站医嘱详情查看组件

调用场景：护士在医嘱列表中点击【查看】图标，需在列表下方查看医嘱详情。

调用入口：医嘱列表行悬浮操作区中的【查看】图标。

核心入参：

- orderId；
- encounterId；
- patientId；
- source = OUTPATIENT_NURSE_ORDER。

核心出参：

- 医嘱详细内容；
- 医生站主状态；
- 医嘱变更明细；
- 审方、收费、执行等主结果摘要。

调用后处理：

- 护士站只做展示，不修改主数据；
- 若返回结果与本地投影字段不一致，以医生站主结果为准；
- 视需要刷新当前医嘱列表。

### 4.2.7.4.3.2 门诊医生站医嘱属性编辑组件 / 接口

调用场景：护士点击【编辑】按钮后，需由医生站判断哪些字段允许修改并完成主数据更新。

调用入口：医嘱列表行悬浮操作区中的【编辑】图标。

核心入参：

- orderId；
- orderCategory；
- checkinId；
- patientId；
- editableFields；
- operatorId、operatorName。

核心出参：

- 是否更新成功；
- 医生站认可的最终字段值；
- 当前可编辑字段范围；
- 是否仍允许签收。

调用后处理：

- 医生站更新成功后，护士站再更新 `outp_nurse_order_ext`；
- 若医生站拒绝修改，则护士站不回写本地扩展字段；
- 页面提示以医生站返回结果为准。

### 4.2.7.4.3.3 门诊医生站医嘱转录组件

调用场景：护士点击【转录】按钮，调用医生站提供的组件开立医嘱。

调用入口：医嘱处理区域右上方【转录】按钮。

核心入参：

- checkinId；
- encounterId；
- patientId；
- clinicId；
- doctorId；
- source = OUTPATIENT_NURSE_ORDER；
- operatorId、operatorName。

核心出参：

- 是否转录成功；
- 新开立医嘱主键集合；
- 是否需医生确认；
- 是否进入审批流程；
- 是否需要刷新列表。

调用后处理：

- 护士站不直接写医生站医嘱主表；
- 若转录结果为待确认或待审批，则对应医嘱不可签收；
- 返回成功后刷新医嘱列表展示。

### 4.2.7.4.3.4 HIS 补记账组件

调用场景：护士点击【补记账】按钮，调用 HIS 记账组件执行补记账。

调用入口：医嘱处理区域右上方【补记账】按钮。

核心入参：

- encounterId；
- patientId；
- orderId 或选中的医嘱集合；
- patientVisitScope（门诊 / 住院）；
- operatorId、operatorName。

核心出参：

- 是否处理成功；
- 补记账单据主键；
- 费用处理结果；
- 是否刷新医嘱收费标识。

调用后处理：

- 住院患者补记账、门诊患者补记账调不同组件；
- 主收费结果以 HIS 为准；
- 如护士已勾选“暂不收费”，则仅回写护士站投影字段，不覆盖 HIS 主结果。

### 4.2.7.4.3.5 护理文书报价单组件

调用场景：护士打开护理文书中的费用预估单，并导入当前医嘱数据生成报价单。

调用入口：医嘱处理区域右上方【报价单】或护理文书中的费用预估单入口。

核心入参：

- checkinId；
- encounterId；
- patientId；
- selectedOrderIds；
- quoteType；
- operatorId、operatorName。

核心出参：

- quoteDocId；
- 已导入医嘱集合；
- 是否允许打印；
- 是否允许继续手工补充项目。

调用后处理：

- 护士站不单独维护报价单主表；
- 报价文书由护理文书模块负责归档与打印；
- 如需回显报价状态，可按展示需要回写投影字段。

### 4.2.7.4.3.6 医技预约组件 / 系统接口

调用场景：护士点击【医技预约】按钮，调医技预约界面进行预约、修改、取消、查看操作。

调用入口：医嘱处理区域右上方【医技预约】按钮。

核心入参：

- checkinId；
- encounterId；
- patientId；
- orderId；
- orderCategory；
- source = OUTPATIENT_NURSE_ORDER。

核心出参：

- appointmentId；
- appointmentStatus；
- appointmentTime；
- 是否需要刷新医嘱列表。

调用后处理：

- 医技预约系统负责主业务处理；
- 护士站只做上下文透传和结果回显；
- 需要在页面展示预约状态时，可通过投影回写接口更新 `outp_nurse_order_ext`。

### 4.2.7.4.3.7 门诊医生站入院单组件

调用场景：护士点击患者列表中的入院单提醒图标，或右侧功能按钮【入院单】时，打开门诊医生站入院单组件。

调用入口：患者列表入院单提醒图标、医嘱处理区域或右侧功能按钮【入院单】。

核心入参：

- checkinId；
- encounterId；
- patientId；
- admissionNoteId（如已有）；
- source = OUTPATIENT_NURSE_ORDER。

核心出参：

- 是否成功打开；
- admissionNoteId；
- 入院单状态；
- 是否需要刷新提醒标识。

调用后处理：

- 入院单主数据由医生站模块负责；
- 护士站仅负责上下文透传与提醒标识刷新；
- 如需在列表中展示“存在入院单”，可按展示需要同步提醒字段。

### 4.2.7.4.3.8 药房审方 / 发药结果查询接口

调用场景：医嘱列表需要展示审方通过/不通过、已收费/未收费、分批发药等药品相关结果时，需读取药房或相关系统返回的主结果。

调用入口：

- 医嘱列表加载；
- 医嘱详情查看；
- 签收完成后刷新。

核心入参：

- orderId；
- encounterId；
- patientId；
- orderCategory = DRUG。

核心出参：

- 审方结果；
- 发药结果；
- 分批发药相关主结果；
- 需要在护士站展示的药品状态摘要。

调用后处理：

- 药房结果为主，护士站不重复定义审方和发药主状态；
- 若页面需要长期展示，可由投影回写接口同步少量字段到 `outp_nurse_order_ext`；
- 发生口径冲突时，以药房 / 医生站主结果优先。
