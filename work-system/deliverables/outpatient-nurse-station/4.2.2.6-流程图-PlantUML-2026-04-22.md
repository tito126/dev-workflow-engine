# 4.2.2.6 流程逻辑 - PlantUML

> 说明：本节对应 `4.2.2.6` 下 3 个核心流程图，分别对应 Banner 配置项查询、Banner 业务值查询与组装、Banner 前端渲染与悬浮展示。

---

## 4.2.2.6.2 Banner 配置项查询流程

```plantuml
@startuml
start
:前端发起 Banner 配置项查询请求;
:读取 wardId、encounterTypeCode、emergencyTypeCode、appSystemCode、hospitalSoid;
:查询 INP_BANNER_DISPLAY_ADAPT 基础显示项定义;
:查询 BANNER_DISPLAY_WARD_SETTINGS 病区展示配置;
:按 BANNER_DISPLAY_ITEM_ID 关联基础项与病区配置;
if (是否命中病区特定配置?) then (是)
  :取病区特定配置项;
else (否)
  :按基础显示项默认规则补齐;
endif
:过滤逻辑删除和无效配置项;
:按 SEQ_NO 排序;
:返回配置项列表、样式信息和 hoverEnabled 标志;
stop
@enduml
```

---

## 4.2.2.6.3 Banner 业务值查询与组装流程

```plantuml
@startuml
start
:前端发起 Banner 业务值查询请求;
:读取 patientId、wardId、场景参数、bannerDisplayItemIds;
:查询患者基础信息;
:获取头像、序号、性别、年龄等固定信息;
:根据 propertyName 汇总待查询属性;
:查询患者扩展属性/业务摘要信息;
if (配置项是否为固定文案类?) then (是)
  :优先取配置中的固定展示值;
else (否)
  :取患者实际业务值;
endif
if (动态项是否取到值?) then (是)
  :写入对应展示项;
else (否)
  :返回空值，不影响其他项展示;
endif
:合并固定信息与动态展示项;
:按配置顺序输出最终 Banner 数据;
stop
@enduml
```

---

## 4.2.2.6.4 Banner 前端渲染与悬浮展示流程

```plantuml
@startuml
start
:前端接收 Banner 最终展示数据;
:渲染固定信息区域;
:按排序渲染动态展示项;
:检测当前行是否存在溢出项;
if (是否存在溢出?) then (否)
  :正常展示 Banner 内容;
  stop
else (是)
  :保留当前行展示效果;
  :等待鼠标悬浮操作;
  if (用户是否悬浮到溢出区域?) then (是)
    :展示当前 Banner 数据中的完整内容;
    :按原样式显示悬浮信息;
  else (否)
    :维持当前展示状态;
  endif
endif
stop
@enduml
```
