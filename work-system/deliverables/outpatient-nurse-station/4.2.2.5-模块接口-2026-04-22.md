4.2.2.5 模块接口

本节用于说明门诊护士站患者 Banner 模块涉及的后台接口，重点描述系统在什么场景下被调用、需要传递哪些参数、返回哪些结果，以及配置匹配、数据组装和异常处理的边界。

本模块当前提供以下两个后台接口：
配置项查询接口；
Banner 业务值查询接口。

其中，配置项查询接口负责返回当前场景下“需要展示哪些 Banner 信息”；业务值查询接口负责返回这些 Banner 配置项对应的实际展示值。前端据此完成患者 Banner 渲染；当一行展示不下时，仍基于同一批返回结果做悬浮查看，不单独拆分新的接口。

4.2.2.5.1 后台接口

4.2.2.5.1.1 Banner 配置项查询接口

接口地址：GET /api/outpatient-nurse/banner/config-items

功能说明：根据当前病区、就诊类型、急诊类型和应用系统代码，查询当前患者 Banner 应展示的配置项列表，返回基础显示项定义和病区展示配置匹配后的结果。

调用方：门诊护士站前端页面。

触发时机：
操作员打开单患者菜单时；
病区切换时；
就诊场景变化或 Banner 配置刷新时。

请求参数：
wardId；
encounterTypeCode；
emergencyTypeCode；
appSystemCode；
hospitalSoid。

返回结果：
是否查询成功；
当前场景下需要展示的 Banner 配置项列表；
每个配置项的显示项标识、显示项名称、属性名称、排序、背景色、字体色；
固定展示项标志；
是否支持悬浮查看。

返回示例如下：

JSON
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "hoverEnabled": true,
    "configItems": [
      {
        "bannerDisplayItemId": "BDI_001",
        "displayItemName": "过敏信息",
        "propertyName": "allergyInfo",
        "seqNo": 10,
        "basicDisplayItemFlag": 1,
        "backgroundColor": "#FFF4E5",
        "fontColor": "#D46B08"
      },
      {
        "bannerDisplayItemId": "BDI_002",
        "displayItemName": "患者偏好",
        "propertyName": "patientPreference",
        "seqNo": 20,
        "basicDisplayItemFlag": 0,
        "backgroundColor": "#F6FFED",
        "fontColor": "#389E0D"
      }
    ]
  }
}

异常处理：
参数缺失时返回失败信息；
若未命中病区特定配置，则按基础显示项默认规则补齐；
逻辑删除配置项不参与返回；
查询异常时记录统一日志。

4.2.2.5.1.2 Banner 业务值查询接口

接口地址：GET /api/outpatient-nurse/banner/business-values

功能说明：根据患者标识和配置项列表，查询患者 Banner 对应的实际业务值，返回固定信息和动态展示项值，供前端完成 Banner 渲染。

调用方：门诊护士站前端页面。

触发时机：
Banner 配置项加载完成后；
患者切换时；
患者信息变化后需刷新 Banner 时。

请求参数：
patientId；
wardId；
encounterTypeCode；
emergencyTypeCode；
appSystemCode；
bannerDisplayItemIds。

返回结果：
是否查询成功；
固定信息（头像、序号、性别、年龄）；
每个 Banner 配置项对应的实际展示值；
展示项排序结果；
是否存在溢出展示内容。

返回示例如下：

JSON
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "patientId": "PAT_10001",
    "fixedItems": {
      "avatarUrl": "https://example.com/avatar/PAT_10001.png",
      "hisRegisterNo": "REG202604220001",
      "gender": "女",
      "age": "32岁"
    },
    "dynamicItems": [
      {
        "bannerDisplayItemId": "BDI_001",
        "displayValue": "青霉素过敏"
      },
      {
        "bannerDisplayItemId": "BDI_002",
        "displayValue": "希望优先安排女护士沟通"
      }
    ],
    "hasOverflow": true
  }
}

异常处理：
患者不存在时返回失败信息；
若某个配置项未查询到业务值，可返回空值，不得影响固定信息和其他配置项展示；
固定文案类配置项可优先返回 `BANNER_DISPLAY_ITEM_VALUE` 对应结果；
查询异常时记录统一日志，不影响页面其他区域操作。
