4.2.2.5 模块接口

本节用于说明门诊护士站患者 Banner 模块涉及的后台接口和调用其他模块接口，重点描述系统在什么场景下被调用、需要传递哪些参数、返回哪些结果，以及配置匹配、数据组装和异常处理的边界。

本节接口分为两类：
后台接口；
调用其他模块接口。

患者 Banner 的配置维护职责不在当前模块内实现，统一由【统一配置-banner 组件】承担；当前模块主要负责按病区 / 就诊场景读取配置，并结合患者实时上下文组装 Banner 展示结果。

4.2.2.5.1 后台接口

4.2.2.5.1.1 患者 Banner 信息查询接口

接口地址：GET /api/outpatient-nurse/patient/banner

功能说明：根据患者、病区和当前就诊场景，查询并组装患者 Banner 展示数据，返回固定信息和动态展示项列表。

调用方：门诊护士站前端页面。

触发时机：
操作员打开单患者菜单时；
患者切换时；
患者相关信息变化后需刷新 Banner 时。

请求参数：
patientId；
wardId；
encounterTypeCode；
emergencyTypeCode；
appSystemCode；
operatorId（如需记录访问上下文）。

返回结果：
是否查询成功；
固定信息（头像、序号、性别、年龄）；
动态展示项列表；
每个展示项的显示值、排序、背景色、字体色；
是否支持悬浮查看。

返回示例如下：

JSON
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "patientId": "PAT_10001",
    "fixedItems": {
      "avatarUrl": "https://example.com/avatar/PAT_10001.png",
      "hisRegisterNo": "REG202604220001",
      "gender": "女",
      "age": "32岁"
    },
    "dynamicItems": [
      {
        "bannerDisplayItemId": "BDI_001",
        "displayItemName": "过敏信息",
        "displayValue": "青霉素过敏",
        "seqNo": 10,
        "backgroundColor": "#FFF4E5",
        "fontColor": "#D46B08"
      },
      {
        "bannerDisplayItemId": "BDI_002",
        "displayItemName": "患者偏好",
        "displayValue": "希望优先安排女护士沟通",
        "seqNo": 20,
        "backgroundColor": "#F6FFED",
        "fontColor": "#389E0D"
      }
    ],
    "hoverEnabled": true
  }
}

异常处理：
参数缺失或患者不存在时返回失败信息；
若统一配置未命中病区特定配置，则按默认项规则补齐；
若患者扩展属性未取到值，则该展示项可返回空值或按配置值回退，不得影响固定信息展示；
关键查询异常需写入统一日志。

4.2.2.5.1.2 患者 Banner 悬浮信息查询接口

接口地址：GET /api/outpatient-nurse/patient/banner/tooltip

功能说明：当 Banner 一行显示不下时，返回当前溢出展示项的完整内容，供前端悬浮层展示。

调用方：门诊护士站前端页面。

触发时机：前端识别 Banner 存在溢出项，且操作员悬浮到对应展示区域时。

请求参数：
patientId；
wardId；
encounterTypeCode；
emergencyTypeCode；
appSystemCode；
overflowItemIds（可选，前端已识别溢出项时传入）。

返回结果：
是否查询成功；
悬浮层是否展示；
溢出展示项名称和值；
对应样式信息（如有需要）。

返回示例如下：

JSON
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "showTooltip": true,
    "tooltipItems": [
      {
        "bannerDisplayItemId": "BDI_002",
        "displayItemName": "患者偏好",
        "displayValue": "希望优先安排女护士沟通"
      },
      {
        "bannerDisplayItemId": "BDI_003",
        "displayItemName": "备注",
        "displayValue": "近三月多次复诊，沟通时需同步关注既往检查结果"
      }
    ]
  }
}

异常处理：
若当前患者 Banner 无溢出项，则返回空结果并标记 `showTooltip=false`；
悬浮查询结果必须与当前 Banner 已匹配出的配置项一致，不允许返回配置外字段；
查询异常时记录统一日志，不影响页面其他区域操作。

4.2.2.5.2 调用其他模块接口

4.2.2.5.2.1 调用统一配置 Banner 配置查询接口

调用场景：患者 Banner 组装前，需要读取 Banner 基础显示项定义和病区展示配置。

调用目标：统一配置模块。

触发时机：
Banner 首次加载时；
病区切换时；
配置缓存失效或主动刷新时。

核心入参：
wardId；
encounterTypeCode；
emergencyTypeCode；
appSystemCode；
hospitalSoid。

核心出参：
基础显示项定义列表（INP_BANNER_DISPLAY_ADAPT）；
病区展示配置列表（BANNER_DISPLAY_WARD_SETTINGS）；
默认项标志；
排序信息；
样式信息。

调用后处理：
根据 `BANNER_DISPLAY_ITEM_ID` 关联基础项和病区配置；
优先使用病区配置，未命中特定场景时按默认项策略补齐；
逻辑删除数据不参与 Banner 组装。

4.2.2.5.2.2 调用患者基础信息查询接口

调用场景：Banner 渲染时需要获取患者固定展示信息和当前就诊上下文。

调用目标：患者基础信息 / 就诊信息模块。

触发时机：Banner 加载或刷新时。

核心入参：
patientId；
encounterId（如有）；
wardId（如有）。

核心出参：
头像；
HIS 患者登记序号；
性别；
年龄；
当前病区 / 诊区信息；
就诊类型、急诊类型。

调用后处理：
固定信息直接用于 Banner 固定区域展示；
病区和就诊场景信息用于后续 Banner 配置匹配；
如头像缺失，可按前端默认头像规则展示，不影响其他信息返回。

4.2.2.5.2.3 调用患者扩展属性查询接口

调用场景：Banner 动态展示项需要根据 `PROPERTY_NAME` 获取患者实时属性值。

调用目标：患者扩展信息 / 患者摘要 / 标签聚合模块。

触发时机：Banner 基础项与病区配置匹配完成后。

核心入参：
patientId；
propertyNames；
encounterId（如有）；
wardId（如有）。

核心出参：
属性名与属性值映射；
属性更新时间；
必要时的值来源标识。

调用后处理：
按 `PROPERTY_NAME` 将属性值回填到对应 Banner 展示项；
若配置项为固定文案类，可优先使用 `BANNER_DISPLAY_ITEM_VALUE`；
若动态属性值为空，则可返回空展示值，不得影响其他展示项输出；
如扩展属性模块异常，需记录日志并保留 Banner 固定信息展示能力。
