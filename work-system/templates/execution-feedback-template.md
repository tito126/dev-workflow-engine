# 执行反哺记录模板

- 日期：YYYY-MM-DD
- 所属专项：<专项名称>
- 执行载体：<执行型 Agent / ACP / Claude Code / 其他>
- 任务类型：维护 | 优化 | 隔离改造 | 修复 | 脚本 | 治理 | 其他

## 1. 任务背景
这次要解决什么问题？

## 2. 执行内容
做了哪些代码维护、优化、验证或整理动作？

## 3. 当前结果
当前做到哪一步？产出了什么？是否已可提交、可验证、可交接？

## 4. 有效原因
这次为什么推进得动？哪些前提、做法或边界处理起了作用？

## 5. 风险 / 不足
还有哪些不确定点、残留风险、依赖项或需要人工判断的地方？

## 6. 可迁移经验
以后再遇到类似问题，有什么判断规则、执行方法、检查点或治理思路可以复用？

## 7. 对“降本增效”的影响判断
这次更可能降低了什么成本、提升了什么效率？
- 例如：沟通轮次、排查时间、返工概率、实现复杂度、维护成本

- `work-system/projects/active/<专项>.md`
