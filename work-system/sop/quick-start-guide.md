# 工作管控极简指南

## 你平时只需要记住 4 件事

### 1. 想先记住，直接说
- `记录一下：...`
- `先放临时池：...`
- `提醒我：...`

用途：接住临时任务、灵感、风险、提醒。

### 2. 和某个专项有关，直接说
- `归到XX专项：...`
- `更新进展：...`
- `记成风险：...`
- `补充价值：...`

用途：持续更新专项，不用自己找文件。

### 3. 早上开工时说
- `帮我排一下今天的 focus`

用途：我会结合未完成事项、提醒、专项进展，帮你排今天最该推进的事。

### 4. 晚上收工时说
- `帮我做今日总结`

用途：我会帮你收口今天做了什么、哪些没闭环、明天该接什么。

## 现在这套系统的固定结构

不要再随意加层，先稳定用这几块：

- `work-system/inbox/temporary-work-pool.md`：临时事项
- `work-system/inbox/ideas.md`：暂未立项的想法
- `work-system/inbox/reminders.md`：提醒事项
- `work-system/projects/active/`：正式专项
- `work-system/daily/focus/`：今日聚焦
- `work-system/daily/summary/`：今日总结

## 我怎么判断记到哪里

- 临时要记住，但还没成项目 -> 临时池/提醒/灵感
- 已经明确要持续推进 -> 专项档案
- 有明确时间节点 -> 提醒事项

## 哪些话我会先反问，不会直接记

如果你只给一句比较大的方向，比如：
- `做个转写 skill`
- `搞个上下文机制`
- `做个 Cherry Studio agent 壳`

我以后会先反问，确认你的真实意图，再决定怎么记。

我通常会问这类问题：
- 你现在是想先记一个方向，还是准备正式推进？
- 这件事你更想做成 skill、专项，还是只是先留个想法？
- 你最想解决的核心问题是什么？

## 什么时候你不用操心提示词

不用刻意记很多指令。正常说话就行。

只要你表达出以下意思，我就会接：
- 要记住
- 要提醒
- 要归到某个专项
- 要排今天重点
- 要做今天总结

## 当前最重要的原则

- 少而稳，不追求复杂
- 正式记录落文件，不只靠记忆
- 大方向先问清楚，再决定怎么记
- 不轻易新增层级
