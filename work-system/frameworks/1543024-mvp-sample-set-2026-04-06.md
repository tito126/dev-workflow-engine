  - 交互保留为“类型切换 + 日期范围”。
  - 仅在“已出院”场景显示。
  - “更多搜索”中不再重复展示同一条件。
- 验收口径：页面展示正确、场景控制正确、参数传递正确、无重复入口。
- 如何验证：页面行为验证 + 参数链路检查 + 条件去重验证。
