# nurse-station pattern ledger

> 用于沉淀护士站研发需求开发中的可复用模式、边界规则、流程缺口。
> 来源默认是各任务的 `acceptance.md` / `retrospective.md`。
> 这里只记“可反哺 skill 的模式”，不记普通任务流水。

---

## 使用规则

1. 新模式先进入“待确认模式”，不要一上来直接升格成正式规则
2. 每条模式都必须带来源任务，避免脱离证据拍脑袋抽象
3. 同类模式重复出现，或已经确认值得固化进 skill 时，再移入“已确认模式”
4. 如果模式后来被证伪、只适用于个别医院、或会误导默认流程，移入“废弃 / 不成立模式”
5. 后续是否共享到团队地址，先等本地试跑样本足够后再决定；当前默认先在本工作区集中维护
