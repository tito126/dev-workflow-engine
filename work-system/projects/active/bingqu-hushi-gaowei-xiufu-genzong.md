## 专项定义
围绕金山表格《【内部】临床&医管高危代码修复计划》中 `病区护士（姚云）` 工作表，对下周需推进的问题清单进行整理、分批修复、AI 辅助优化与长期追踪。

## 当前判断
- 这不是一次性修复任务，而是持续扫描 → 分批治理 → 回归验证 → 新问题继续纳入的长期工作流。
- 更适合按“问题池 + 分批推进 + 周期复盘”管理，而不是当成单次清单处理。
- AI 的价值不只在首轮修复建议，还应长期用于：聚类问题、识别共性根因、生成修复草案、辅助复盘与补充后续扫描结果。

## 本轮目标
- 先完整收编 `病区护士（姚云）` 工作表内容为 Markdown。
- 基于清单形成下周执行视图。
- 下周提醒第别优先用 AI 做首轮分析和分批优化。
- 后续把新增扫描问题持续补入同一档案，形成长期跟踪面板。

## 推荐工作流
1. 先把原始问题清单转成 Markdown 可编辑版本。
2. 用 AI 做首轮分类：按模块 / 风险级别 / 修复类型 / 是否可批量处理分组。
3. 拆成若干批次，而不是一次性全修。
4. 每批记录：问题范围、修复负责人、预计收益、回归方式、遗留风险。
5. 每次新扫描结果继续并入同一清单，维护“新增 / 处理中 / 已关闭 / 待复扫”状态。
6. 每周至少做一次小复盘：哪些问题是重复模式，哪些可以沉淀成规则或自动化检查。
