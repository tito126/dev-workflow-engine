## 推荐工作流
1. 先把原始问题清单转成 Markdown 可编辑版本。
2. 用 AI 做首轮分类：按模块 / 风险级别 / 修复类型 / 是否可批量处理分组。
3. 拆成若干批次，而不是一次性全修。
4. 每批记录：问题范围、修复负责人、预计收益、回归方式、遗留风险。
5. 每次新扫描结果继续并入同一清单，维护“新增 / 处理中 / 已关闭 / 待复扫”状态。
6. 每周至少做一次小复盘：哪些问题是重复模式，哪些可以沉淀成规则或自动化检查。
