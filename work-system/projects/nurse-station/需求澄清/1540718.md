## 技术分析

### 当前SQL示例
```sql
select a.* from EXEC_PLAN a
where a.IS_DEL = 0
  and a.HOSPITAL_SOID in ('992005')
  and a.PLANNED_EXEC_AT >= '2026-03-26 00:00:00.0'
  and a.PLANNED_EXEC_AT <= '2026-03-27 23:59:59.0'
  and (a.EXEC_FLOW_ID in ('424566890975733772'))
union
select a.* from EXEC_PLAN a
where a.IS_DEL = 0
  and a.HOSPITAL_SOID in ('992005')
  and a.PLANNED_EXEC_AT >= '2026-03-26 00:00:00.0'
  and a.PLANNED_EXEC_AT <= '2026-03-27 23:59:59.0'
  and (a.GOODS_FLOW_ID in ('424566890975733772'))
```

### 优化方向
1. **时间分批**: 按时间窗口（如1天）分批查询
2. **并发执行**: 多线程并发查询多个批次
3. **结果合并**: 合并分批结果，保持顺序
4. **索引优化**: 检查 `PLANNED_EXEC_AT` 字段索引

### 风险点
1. **线程池管理**: 多线程并发可能带来新的复杂性
2. **结果合并顺序**: 分批结果顺序需与原始查询一致
3. **内存占用**: 并发查询可能增加内存压力
4. **事务处理**: 每个批次需独立事务
