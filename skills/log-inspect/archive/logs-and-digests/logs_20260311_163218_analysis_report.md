### 3.2 需要改进的日志内容

**开发团队应改进的日志**:

1. **空指针异常** - 添加上下文信息
   ```java
   // 不好
   log.error("null");
   
   // 好
   log.error("查询患者信息失败，patientId为null, encounterId={}", encounterId);
   ```

2. **认证过期** - 添加traceId
   ```java
   // 不好
   log.error("认证过期,请重新刷新");
   
   // 好
   log.error("[{}] 认证过期,请重新刷新, userId={}, token={}", traceId, userId, tokenPrefix);
   ```

3. **费用查询错误** - 添加详细原因
   ```java
   // 不好
   log.error("查询费用信息错误，encounterId={}", encounterId);
   
   // 好
   log.error("查询费用信息错误，encounterId={}，原因：{}", encounterId, e.getMessage());
   ```
