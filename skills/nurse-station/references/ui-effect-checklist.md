# ui-effect-checklist — UI 效果排查清单

当代码已改但页面不生效时，先按这份清单排查，不要默认判定实现失败。

## 检查清单

1. **入口事件是否真的触发**：绑定的 click / change / submit 事件是否被执行
2. **显隐条件是否满足**：v-if / v-show 条件是否为 true
3. **权限 / 配置开关是否挡住了**：功能开关、角色权限、科室配置等
4. **弹窗是否被遮挡**：z-index 层级、modal 叠加、overlay 覆盖
5. **容器层级是否异常**：是否渲染到了错误容器、父容器 overflow:hidden 截断
6. **路由或组件是否真的挂载**：路由守卫、动态加载、异步组件是否完成
7. **是否命中了旧分支 / 缓存**：是否跑的是本轮目标仓库目录下已同步到最新基线分支的代码，还是旧目录 / 旧分支 / 旧缓存
8. **是否渲染到了错误容器**：teleport / portal 挂载点是否正确

## 结论要求

- 必须区分"代码逻辑未接上"与"效果呈现未显现"
- 如果是 UI 承载问题，先修复承载，再判断需求是否失败
- 如果是弹窗遮挡 / 显隐条件 / 入口挂载问题，不应计入"实现失败"
