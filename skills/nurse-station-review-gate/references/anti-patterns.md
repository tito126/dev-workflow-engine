# Nurse Station Review Gate Anti-Patterns

## Do not do these

1. **把需求符合性和代码质量混成一句话**
   - 这会导致“业务没对，但代码挺整洁”也被放过。

2. **只看实现者摘要，不读真实文件或真实结论**
   - Review 不能只复述 implementer 的说法。

3. **Gate 1 没过就做 Gate 2**
   - 需求不对，代码再整洁也不能继续往下。

4. **问题发现后不回环**
   - review 发现问题就应该返回修正，不是备注一下继续过。

5. **为了推进而降低标准**
   - “差不多”不是通过标准。
