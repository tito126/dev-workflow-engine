# Planning Runtime Examples

## Example 1: Nurse-station MVP run

Use runtime when:
- a real TFS demand is entering intake -> plan -> locate -> implement -> review -> verify
- the work will likely span multiple turns
- later retrospective should be evidence-based

Recommended runtime path:
`work-system/projects/active/<project>/runtime/2026-04-06-nurse-station-mvp-run/`

## Example 2: High-risk issue clustering

Use runtime when:
- a batch of issues must be read, grouped, compared, and converted into phased treatment strategy
- findings and clustering logic should persist across turns

## Example 3: Log-inspection redesign

Use runtime when:
- a log-analysis tool needs multi-step diagnosis, redesign, validation, and report rule changes
- the task includes many findings and intermediate decisions
